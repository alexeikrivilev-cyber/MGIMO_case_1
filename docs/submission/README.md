## Скриншот-план (что снимать для PDF)

1. **Демо-путь**: `project/README.md` → `project/brief.md` →
   `project/options.md` (таблица вариантов) → `project/strategy-product.md`
   (инициативы + приёмный чек-лист) → `project/verification-plan.md`
   (пороги) → `project/decisions.md` (реестр D1–D4).
2. **Запуск по инструкции**: терминал с `python3 -m pytest tests/ -q`
   (553 зелёных) и гейтами (§1.1 README) — доказательство «запуск по
   инструкции без скрытых настроек».
3. **Живой прогон агента**: `opencode run "Выполни шаг 0…"` — вывод
   сессии + строка учёта в `COST.md` (хук cost-append).
4. **Прозрачность**: `STATE.md` (resume-карта), `LOG.md` (журнал),
   `COST.md` + вывод `cost_report.py`.
5. **Гейты в работе**: `eval/runs/t18-case/gates/*.gate.txt` (провалы
   раундов ревизии и зелёные финалы) + `manifest.md` (коды, sha256).
6. **Стенд измерений**: `docs/research/measurements.md` (§23.5 абляция,
   §14 council-lite, §27–§32 серии) + `eval/runs/t13-blindpairs/pairs.md`
   (слепые пары для владельца).
7. **Продолжение после перерыва**: коммит `98d17d6` (WIP-чекпоинт, в
   сообщении зафиксировано убийство сессии внешним SIGINT) и коммит
   `3b0cc84` — возобновление из `STATE.md` новым чатом, доведено до
   зелёного; журнал возобновлённого прогона —
   `eval/runs/t18-case-heldout/manifest.md`. Хеши приведены по текущей
   истории: при выводе сырья прогонов из git все хеши коммитов
   изменились, прежние ссылки на `8cc19ac` удалены.
