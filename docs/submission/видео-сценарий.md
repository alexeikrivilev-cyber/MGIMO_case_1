# Сценарий видео для записи владельцем (≤10 мин, по требованиям ТЗ)

ТЗ требует: «Видеозапись работы агента до 10 минут — обязательно. Сквозной путь
демонстрационного проекта: запрос, работа агента, варианты, стратегия,
продолжение после перерыва.»

Референс по содержанию и порядку — `docs/submission/видео-агент.mp4` (3:12):
тот же сквозной путь, собран из РЕАЛЬНЫХ файлов проекта (лог прогона,
артефакты, вывод гейтов). Можно смотреть по нему и записывать своё.

Рекомендуемая длительность — 5–7 минут: меньше 5 не раскрывает сквозной путь,
больше 7 утомляет жюри. Ниже — таймкоды и что показывать.

## Технические требования к записи

- Длительность ≤10 минут (рекомендуется 5–7).
- Формат: mp4, 1080p (или 720p), звук — голос диктора.
- Обязательно показать: запрос → работу → варианты → стратегию → продолжение после перерыва (5 элементов ТЗ; отсутствие любого = невыполнение требования).
- Экран должен быть читаемым: шрифт терминала ≥16px, зум на ключевые строки.
- Ссылку выложить на Яндекс Диск / Google Диск / VK Видео / RuTube / YouTube — по ТЗ.

## Чего не делать

- Не вырезать провалы гейтов: «провал → ревизия → зелёные» — это доказательство
  рабочего процесса, а не недостаток (реальный лог — `eval/runs/t18-case-launch.log`).
- Не показывать ключи: `STEPFUN_API_KEY` только через окружение.
- Не заявлять то, чего нет в измерениях: что подтверждено, а что нет —
  `docs/research/measurements.md`.
