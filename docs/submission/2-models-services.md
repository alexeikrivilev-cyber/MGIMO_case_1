# 2. Перечень моделей, сервисов и инструментов

## Модели

| Модель | Где используется | Зачем | Прайс (доступ 2026-11-16) |
|---|---|---|---|
| `stepfun/step-5-preview` | все сессии агента, критика, стенда | единственная рабочая модель продукта; mid-tier, reasoning в output | $1.00/M input (cache-miss), $0.10/M cache-read, $2.70/M output |
| `stepfun/step-3.7-flash` | замер демейшена шага 2 (O5-A) | проверка гипотезы «дешёвая модель для шага исследования» | дешевле step-5; замер — отрицательный, демейшн не принят |
| Sonnet 5.5 (Hermes, день 1) | 2 сабагента исследования экосистемы | первичный research «агент-как-папка», 23 API-вызова | ~$8.87 (учтено в dev-контуре) |

Перечень намеренно короткий: замеры показали, что число моделей и
агентов само по себе не преимущество (абляция §23.5: прирост несут
инструкции и навыки, не гетерогенность).

## Сервисы

| Сервис | Зачем | Обязательность |
|---|---|---|
| StepFun API (OpenAI-совместимый эндпоинт) | inference всех сессий | платный, ключ только через env (`{env:STEPFUN_API_KEY}`) |
| OpenCode CLI (1.19.5) | целевая среда: сессии, хуки, инструменты | целевая среда разработки и прогонов |
| Node.js 18+ | плагин хуков `.opencode/plugins/strategy-hooks.ts` | зависимость хуков (`npm install` в `.opencode/`) |
| Docker (v29.1.3 на хосте) | бенчмарк DABstep (Adyen/HF, CC-BY-4.0) на step-5 | только для стенда; в продукте не требуется |
| GitHub API (read-only) | дерево и файлы mattpocock/skills (326k звёзд) для декомпозиции | вне потока прогонов, чтение |
| Браузер | живая ре-проверка URL из evidence и артефактов | верификация источников |

## Инструменты (в репозитории)

- `scripts/check_*.py` — 14 гейтов (§1 архитектуры).
- `scripts/apply_revision.py` — точечные правки артефакта по находкам
  критика с integrity-гейтом (заголовки, «оставить как есть»,
  размер ≥60%).
- `scripts/run_critic.py` — критик с изолированным контекстом; пакетный
  режим; гейт на пустой выход при exit=0.
- `scripts/recover_state.py` — восстановление битого STATE.md из git.
- `scripts/cost_report.py` — сводка расходов по обоим контурам.
- `eval/run_ab.py` — A/B-стенд рук (skill / critic-loop / council-lite /
  curation / lean / hybrid).
- `eval/run_full_case.py` — полный путь шагов 0–5 с гейтами, ревизиями
  и критиком; идемпотентность.
- `product/agent/skill_evolve.py` — CLI журнала самоулучшения навыков
  (propose/apply/rollback/verify/log/status).

## Отказ от инструментов (с данными)

- **MCP web-search**: отклонён (R5) — замер показал, что поиск в
  прогонах не подключён, а живая проверка источников делается браузером
  дешевле и воспроизводимее.
- **DABstep как инструмент итераций промпта**: отклонён — Δ=1 задача
  требует 39 прогонов/руку ≈ $76 против ночного бюджета ~$10; остаётся
  smoke-тестом стенда.
- **Явный кэш брифа**: отменён — провайдерский кэш префикса уже даёт
  ~$0.18/руку естественной экономии (§19.3).
