## Ошибки и как они закрывались (все — в LOG.md, не стёрты)

1. **Потеря финального текста сессии** (task 18, замер 1): при
   контракте «открой файлы инструментами» сессии шагов 2–3 вернули
   48 байт нарратива при 37 170 out-токенах в счётчике; гейты прошли
   вакуумно на файле-заглушке. Починка класса: инлайн-входы + порог
   годности артефакта (≥2000 символов + заголовок) + ретрай. $0.25
   учтены как затраты дефектного контракта.
2. **Пустой выход критика при exit=0** (task 7–9): гейт в
   `run_critic.py` + тест; провальные клетки перепрогнаны.
3. **Парсер частичной оценки** (task 15): «Итого: 24/40 по оценимому…»
   считался полной оценкой — без починки знак Δ серии был бы обратным.
4. **Резолв evidence «<файл>.md §N»** (task 15): предохранитель резолвил
   §N в measurements.md по умолчанию — найдено живой пробой.
5. **Гонка метки прогона** (task 6): раннеры писали метку в STATE.md и
   затирали правки агента → метка вынесена в `eval/.cost-label`.
6. **Тест с побочным эффектом** (task 15): `recover_state` на живом
   репозитории без --dry-run откатил STATE.md и стёр правки очереди →
   тест переведён на dry-run; правки восстановлены вручную.
7. **E2BIG** (О4-хвост): промпт 133 КБ одним argv → `chunk_prompt`.
8. **502 провайдера** (task 11): добор цепочки после сбоя.
9. **Три дефекта контракта рубрики** (task 16): битая таблица, жёсткое
   имя рубрики в промпте, конфликт OUTPUT_FORMAT — стоили перепрогонов
   ($1.42 против предрасчёта ~$0.70).
10. **Преждевременные коммиты** (tasks 6–17 + коммит e467ed6 задачи 19):
    11 коммитов содержали только TASK-файл при заявленной готовности —
    каждый раз работа выполнена заново, факт зафиксирован в LOG.md;
    гейт `check_commit_scope.py` принят как механический ответ.
11. **Базовый дефект check_ranges** (task 18): exit 2 на
    `project/decisions.md` (§-ссылка + маркер на строке продолжения) →
    гейт переведён на логические строки; находки на 14 артефактах
    воспроизводятся 1:1.
12. **Релакс-режим гейта в прогоне** (task 19, найдено при сдаче):
    артефакты в `eval/runs/` проверялись по правилу журнала, а копии в
    `project/` — строго; перенос вскрыл 7 находок sources и 3 находки
    evidence-links → правки оснований (не содержания), все гейты
    перепрогнаны, manifest обновлён с честной записью раунда.
13. **Дефект изоляции стенда §23.0** (верифицирован пробами): in-repo
    сессии получают AGENTS.md через конфиг — это конфундило руки
    стенда; чистый контроль только прямым вызовом API. Правка конфига
    осознанно не делалась, ограничение названо.
14. **Пустые выходы сессий шага 3 на held-out** (task 18, возобновление):
    две сессии одного запуска вернули 0 символов при exit=0; порог
    годности артефакта сработал как задумано (обнаружил, сделал ретрай
    свежей сессией), но ретрай тоже вернул пусто → запуск остановлен с
    явным ПРОВАЛОМ в manifest; возобновление с шага 3 прошло весь путь
    зелёным. Оба факта — в manifest прогона, не спрятаны.
