## Найденное и исправленное в процессе самопроверки (не спрятано)

1. Коммит задачи 19 (в старой истории `e467ed6`) содержал только
   TASK-hermes-19.md — 11-й преждевременный коммит; работа выполнена
   заново, факт зафиксирован. Хеш не резолвится в текущей истории (после
   вывода сырья прогонов из git 2026-11-18 хеши изменились) — назван как
   исторический; проверяемая опора класса дефекта — гейт
   `scripts/check_commit_scope.py`.
2. Гейты строгого режима вскрыли 10 находок на копиях `project/`
   (релакс-режим прогона их маскировал) — правки оснований, перепрогон,
   честная запись в manifest.
3. README-команда `python3 -m pytest` падала без объявленной зависимости —
   добавлен `requirements.txt` + venv-путь, проверен на чистом окружении.
4. **TASK-hermes-20 (блокер сдачи, повторный проход 00:45):** заявленная
   «зелёность всех гейтов» была неверной для acceptance (exit=2, 3
   нарушения) и actionability (exit=2, 9 нарушений) — гейты применялись
   только к strategy-product.md (дефект области действия драйвера и хука).
   Починка класса (драйвер + хук + шаблоны + навыки + регрессы), ревизия
   трёх артефактов реальным содержанием через механизм продукта
   (patch + apply_revision, $0.44), перепрогон всех гейтов на обоих
   деревьях exit 0. Побочно: decisions.md лежал в код-фенсе — гейты
   проходили на нём вакуумно; integrity-гейт откатывал правки,
   переименовывающие заголовки (прецедент H-C2) — оба класса закрыты
   регрессами.
5. sha256 в финальной сводке manifest не совпадали с файлами (правки после
   прогона) — обновлены с записью коррекционного раунда.
