# GigaCode Rules — адаптер «Стратега»

Тонкий адаптер (PRD §6): единый источник истины — `AGENTS.md` в корне
репозитория. Этот файл не дублирует инструкции, а указывает на них,
чтобы правила «Стратега» подхватывались в средах, читающих
`.gigacode/rules/*.md`.

## Что читать

1. `AGENTS.md` (корень репозитория) — постоянные инструкции агента:
   workflow с чекпоинтами, дисциплина доказательств, где что лежит,
   состояние и resume, стоимость, границы.
2. `knowledge/index.md` — карта «вопрос → навык» (progressive
   disclosure: тело навыка открывается только по задаче).
3. `STATE.md` + `LOG.md` — состояние задачи и журнал (читать в начале
   сеанса, до первых действий).
4. `docs/routing.md` — маршрутные решения (процесс/модель/инструмент
   по шагу) и триггер Консилиума.

## Правила, которые не выполняются «по умолчанию» в чужой среде

- Проверки артефактов: `python3 scripts/check_sources.py <файл>`,
  `python3 scripts/check_options.py <файл>`,
  `python3 scripts/check_state.py` — запускать вручную, если хуков
  среды нет (в целевой среде OpenCode их запускают хуки).
- Стоимость прогонов писать в `COST.md` (прайсы —
  `docs/research/llm-pricing-agent-costs.md`).
- Правки `AGENTS.md` — только через стейджинг
  `docs/agents-md-staged.md` (в среде Hermes гейт
  `protected_instruction_files` блокирует прямую запись; финальное
  размещение делает PO).
