### 1.1 Правила выбора модели (факты окружения, проверены 2026-11-16)

- Доступны: `step-5-preview` (сильное семейство), `step-3.7-flash`
  (дешёвое семейство) — один провайдер, ключ только env (PO R5).
  Embeddings-модели нет (`/v1/models`, quota_exceeded на
  `/v1/embeddings`) → семантические метрики — только прокси.
- Effort по умолчанию medium; высокий — на синтезе и на роли адвоката
  дьявола (PRD §9 + council-design §1: адвокат — самый доказанный
  компонент совета).
- Модель-проход не пишет файлы проекта без явного разрешения шага;
  роли Консилиума — строго read-only (инструкция роли + проверка
  `git status`).

### 1.2 Триггер Консилиума (council-design.md §3, развилка по ставке)

| Триггер | Режим |
|---|---|
| Шаг 3 на демо-задаче и held-out (dev) | Full council (прогон О3 — `project/council/run-2026-11-16-01/`) |
| Шаг 3 в прод, ставка высокая (необратимо / >$ порог / кросс-команда) | Оптимизированный совет — после замера О5 (пока: A1 multi-lens) |
| Шаг 3 в прод, ставка низкая | Off — A1/multi-lens single-agent |
| Явный запрос человека | Full (dev) / A1 (prod) |

Классификацию ставки делает главный агент на рамке (чекпоинт 1) и
подтверждает человек; решение логируется (§4).
