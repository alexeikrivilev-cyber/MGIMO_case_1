# Рука C, поворот 31 — ответ агента (дословно)

> Вопрос РП: По каким признакам пилот останавливают, а не продолжают?
>
> sessionID: ses_e10aa7ddbffeLLJpFX2BBEB61Z

> Рука C, поворот 31 из 36; статус OK, попыток 1

---

Пилот останавливают не по одному плохому числу, а когда метрика попадает в зону «не работает» и остаётся там после сбора данных за отведённый срок — по правилам, записанным заранее.

**Стоп-признаки (verification-plan.md, таблица «Пороги»):**

| Признак | Срок сбора данных до стопа |
|---|---|
| Удержание на 30-й день продолжает снижаться ниже 21% | «старт пилота + 2 цикла по 90 дней» (≈6 мес) |
| Отток новичков 0–3 мес продолжает расти | 2 месяца замеров |
| Разница пилот−контроль <2 п.п. или ≤0 п.п. | после 2-го цикла по 90 дней |
| Эффект таргетинга <1 п.п. общего оттока за цикл | 1 цикл кампании |
| AUC модели <0.75 | локальная валидация с holdout |
| Доля m2m растёт месяц к месяцу | 1 месяц (сигнал эскалации руководству) |
| Доля e-check не снижается; нулевой attach-rate; доля касаний поддержки не растёт | 1 цикл / 30 дней |
| Доставляемость ниже broadcast | 1 кампания |
| Удержание старой базы деградирует ниже baseline | 1 цикл по 90 дней |
| Число подключений падает при росте удержания | 1 месяц |

**Ключевые оговорки:**

- Внутри зоны «рано судить» падение метрики — шум, не стоп-сигнал. Например, по удержанию нельзя судить раньше ≈6 мес [прогноз].
- «Метрика не пошла» само по себе — не пересмотр решения: сначала предрегистрированное правило опровержения, и только при изменении оснований — эскалация в decisions.md.
- Порядок при опровержении: данные → LOG.md → сверка с decisions.md (очередь О3) → остановка и передача человеку.
- Откатывают: механику И3, кампании И4, скоринг И2 при AUC <0.75 [гипотеза]; spend возвращается на адресную коммуникацию оставшемуся квинтилю и минимальную долю на базу.
- Чего не делают: не доливают spend в неработающую механику, не переопределяют пороги постфактум, не усредняют конфликтующие замеры.
- После полного отката де-факто остаётся ВАРИАНТ 4 «оставить как есть» — цена бездействия ~273 тыс. подписчиков на когорту (2.1 млн × 13 п.п.) [прогноз] [допущение] (project/brief.md).
