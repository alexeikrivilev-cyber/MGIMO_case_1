# Рубрика «package» — пакет артефактов задачи (brief → verification-plan), TASK-hermes-6 H4

> Пакетная рубрика: критик оценивает НАБОР артефактов полного пути
> одним прогоном (brief.md → research.md → options.md →
> strategy-product.md → strategy-comms.md → verification-plan.md).
> Ключевое отличие от пофайловой оценки: критерии 1.3 и 2.2 —
> МЕЖартефактные (согласованность выбора, метрики, экономики между
> файлами), их пофайловый критик проверить не может в принципе.
> Контракт выхода оценщика совместим со score_arms (4 ×10 = /40).
